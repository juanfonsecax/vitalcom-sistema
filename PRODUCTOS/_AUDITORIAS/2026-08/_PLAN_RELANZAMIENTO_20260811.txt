│   R1..R4 son cuatro conjuntos GEMELOS — mismo ángulo, mismo creativo,     │
│   mismo público — que existen solo para meterle más presupuesto al        │
│   ángulo sin cargárselo todo a un conjunto. Por eso SE SUMAN y NUNCA      │
│   se comparan entre sí.                                                   │
│                                                                           │

│                                                                           │
│ ── CREATIVO NUEVO DEL MISMO ÁNGULO: no es una réplica ──                  │
│   Es un conjunto NUEVO del mismo ángulo que ESTRENA PIEZA:                │
│      GTR7_NUSAVA_ARDOR_R1 → creativo MA6_OFERTA      (la que ya vende)   │

│                                                                           │
│   Después se preguntan las dos cosas POR SEPARADO:                        │
│     ¿ARDOR sigue siendo buen ángulo? → sumar R1..R5 → CPA del ángulo      │

REGLAS (las 6, no negociables):
  1. CUENTA = donde el objeto REALMENTE vive (GTR0 · GTR1 · GTR7 · GTR13 · CP1).
     Nunca la cuenta de origen. Hoy 4 campañas dicen "GTR0" y ninguna está en GTR0.
  2. ANGULO = el mismo texto en todas las cuentas y todas las réplicas. Es lo que
     permite sumar un ángulo entre cuentas. Si cambia de nombre, la suma se parte.
  3. Separador de campos = "_". Dentro de un campo solo guion medio "-".
     Así el nombre se parte en 4 campos exactos. Un "_" dentro del ángulo rompe todo.
  4. R[N] SIEMPRE, desde el primero. R1 es el original, R2/R3… las réplicas.
     Un conjunto sin R no se sabe si es original o copia.
  5. PROHIBIDO publicar un "- Copia". Se renombra ANTES de darle publicar.
     Es el único momento en que renombrar sale gratis.
  6. Sin emojis ni espacios entre campos. Emoji de estado (🟩/🟦) solo al final.

FASE (campo 3 de la campaña): TEST · ESCALA · ESCALA-[ANGULO] cuando la campaña
  entera corre un solo ángulo.

⚠️ LAS RÉPLICAS SE SUMAN, NO SE COMPARAN. R1 y R3 son el mismo creativo, mismo
   público, mismo presupuesto. Que una venda más es ruido de Poisson, no señal.
   Ejemplo real de GTR1: "DETERIORO COGNITIVO - video" hizo CPA Q21 y su "- Copia"
   Q38 — mismo anuncio. El R[N] sirve para identificar y sumar, nunca para coronar.
